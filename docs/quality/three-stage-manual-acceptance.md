# OfferYou 三段式链路人工验收

## 准备材料

- 一份真实 PDF 简历。
- 一份 JD 文本。
- 可选：JD 截图。

## 验收步骤

1. 上传 PDF 简历。
2. 查看「简历结构校准」是否识别姓名、电话、邮箱、教育背景。
3. 检查是否出现 OCR 风险提示。
4. 输入 JD。
5. 查看建议是否围绕 JD，而不是泛泛改句。
6. 接受一条建议。
7. 生成预览。
8. 确认教育背景、联系方式、工作经历、项目经历位置正确。
9. 导出 PDF。

## 通过标准

- 无乱码进入最终 PDF。
- 教育背景不进入项目经历。
- 弱相关经历被压缩，而不是被硬改成强相关。
- 接受建议后预览同步更新。
- PDF 与预览主要内容一致。
