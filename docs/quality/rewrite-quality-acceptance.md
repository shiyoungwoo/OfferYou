# 改写质量验收说明

## 1. 验收目标

这一轮只验收「AI 改写是否真的可用」，不再把重点放在模板、颜色或页面布局上。

## 2. 通过标准

- 同一份 JD 和简历输入后，改写结果必须能看出岗位定制痕迹。
- 改写结果必须保留真实事实，不得改错公司名、学校名、时间和关键数字。
- 模型失败时，页面或数据里必须能看到中文降级原因。
- 改写结果不得使用「建议」「可以」「这段经历」「相关性较弱」「请补充」等元话语。
- 改写结果不得只复制原文，也不得用省略号截断。

## 3. 失败信号

- 右侧改写内容和左侧原文几乎一致。
- 真实公司名、学校名或数字事实被改错。
- 页面只显示一段看起来像规则引擎拼接的泛化文本。
- 模型降级后没有任何可读说明，导致结果看不出是不是 AI 输出。

## 4. 验收边界

- 不验收模板样式。
- 不验收颜色方案。
- 不验收导航结构。
- 不验收认证、多人协作和数据库重构。
